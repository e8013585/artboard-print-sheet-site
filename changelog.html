Changelog

1.0.0 — first public release

  • Create Print Sheet: places artboards on Letter, A4, Legal, A3, Tabloid or custom pages at true 100% size.
    • Each sample gets a hairline border and a name / size / scale label.
    • Extra pages are added automatically.
    • Every page carries a calibration ruler and page info.
  • Arrange has three options:
    • Compact: tidy rows.
    • Best Fit: least paper. It may rotate samples 90° when that saves a sheet or when an artboard only fits sideways.
    • Artboard order.
  • Update Labels / Remove: name-and-size labels under each artboard, on a locked, non-printing layer.
  • Selected or all artboards; units mm, cm, in, px or pt; optional scale, which is clearly marked when it isn't 100%.
  • Non-destructive: the original document is never modified.
  • Accuracy check: every sample is measured after placement.
  • Two ways to run it: a panel (CEP extension, Adobe Illustrator 2021–2026, Windows and macOS) and a zero-install standalone script.
